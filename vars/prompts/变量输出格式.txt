变量输出格式:
  rule:
    - 在提示词最末尾输出变量更新；这段会被插件摘掉，不会进入图片提示词
    - 整段是一个 JSON 对象，层级与「变量结构」一致
    - 写值 = 设置或新增；值写成空字符串 = 删除该字段；写对象 = 往分组里新增或修改条目
    - 值里可以带三种引用：$路径$（取变量）、$名字-角度-状态-部位$（官方预设调用）、${"name":…}$（官方 JSON 调用）
    - 不要输出 op 或 path，不要输出 JSON Patch 数组
    - 本轮没有任何变化时，整段不要输出；不要写 _ 开头的字段
  format: |-
    <变量更新>
    {
      "角色列表": {
        "爱莉希雅": {
          "人物形象": "$xiao hong-from front-sfw-upperBody$",
          "人物状态": "$角色列表/爱莉希雅/服装列表/比基尼$,$角色列表/爱莉希雅/人物形象$,-gold chain,cumdrip,after sex"
        },
        "神里绫华": {
          "key": "绫华,Ayaka",
          "人物形象": "1.5::kamisato ayaka (genshin impact)::,silver hair,blue eyes",
          "服装列表": { "白无垢": "shiromuku,white kimono" },
          "人物状态": "$角色列表/神里绫华/服装列表/白无垢$"
        }
      }
    }
    </变量更新>
  examples: |-
    初始化角色: { "角色列表": { "爱莉希雅": { "key": "爱莉希雅,Elysia", "人物形象": "1.5::elysia (honkai impact 3rd)::,pink long hair,purple eyes", "服装列表": { "校服": "school uniform,pleated skirt" } } } }
    换装:       { "角色列表": { "爱莉希雅": { "人物状态": "$角色列表/爱莉希雅/服装列表/校服$" } } }
    调用预设:   { "角色列表": { "爱莉希雅": { "人物状态": "$xiao hong-from front-sfw-upperBody$,cumdrip" } } }
    减掉 tag:   { "角色列表": { "爱莉希雅": { "人物状态": "$角色列表/爱莉希雅/人物形象$,-hat" } } }
    恢复状态:   { "角色列表": { "爱莉希雅": { "人物状态": "" } } }
